## Standing rules (every agent on this project reads these)

`AGENTS.md` is the rulebook. `CLAUDE.md` is a symlink to it, so every agent tool reads the same text.

- **Read PLAN.md first where it exists; it is the contract.** Own only your slice's files.
- **What "done" means:** verified, committed (only your own paths, with a message that says what and
  why), and shown: screenshots of anything visible, phone and desktop where it matters. Never hand back
  an empty screen; seed demo data if the page needs it.
- **Nothing leaves without the owner.** Emails, forms, posts, releases and pull requests to other
  people's repos are staged; the owner presses send.
- **Tests that cannot lie.** Every new check is shown to go red once. A bug that reached a person gets
  a test that fails without the fix. Real input and hit-tests for anything a browser shows.
- **Fresh eyes before done.** Medium and big jobs get a review by someone who didn't write the code.
- **Stop only what you started.** Never kill a process by name or free a port you don't own.
- **Keep this file short:** commands, gotchas with a why, hard rules.
